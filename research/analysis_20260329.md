## 製品①：GymBars PRO（Robus Athletic）

### 基本情報
| 項目 | 内容 |
|------|------|
| メーカー | Robus Athletic（エストニア） |
| プラットフォーム | Kickstarter |
| 発売時期 | 2024年1〜2月 |
| 調達金額 | $95,924（目標$5,000 → 達成率**1,918%**） |
| 支援者数 | 412名 |
| 価格帯 | $169〜232（早期割引〜通常） |
| 円換算 | 約24,500〜33,600円 |
| 重量 | ~0.5kg（推定） |
| Amazon Japan | **未出品**（確認済） |
| 日本代理店 | **なし**（確認済） |

### 製品特徴
- ガラス繊維強化ポリマー製バー＋高品質ラテックスバンド（最大120kg負荷）
- **AIトレーナー搭載アプリ**でレップ数・負荷を自動追跡
- ドアアンカー装着でケーブルマシン化（ラットプルダウン・ロウ対応）
- 1回の充電で約10時間分のトレーニングに対応
- コンパクト収納（既存のジムの10倍のポータビリティを謳う）

### 4軸スコアリング

#### 市場需要（**24/25点**）
日本のカリステニクスブームは2020年以降右肩上がり。自重トレーニング×スマート管理の組み合わせは国内に類似品がほぼ存在しない。KAMUI PARKのコアターゲット（20〜40代・自重トレーニング愛好家）にドンピシャ。-1点は「スマートトラッキングへの理解度がまだ普及途上」のリスク。

#### 競合状況（**23/25点**）
Amazon Japan検索でGymBars PRO相当の「ラテックスバンド×スマートトラッキング×アプリ連動」製品は存在しない。類似品（テラバンド等）はあるがスマート機能を持たない。-2点は将来的な中国製コピー品参入リスク。

#### 法規制適合（**25/25点**）
電動部分なし（アプリ連動はBluetooth通信のみ）。運動器具として輸入規制の対象外。PSC対象外。薬機法との関係なし。最もリスクフリーなカテゴリ。

#### 価格競争力（**20/25点**）
推定仕入れ価格: $80〜100（約11,600〜14,500円）
想定販売価格: 29,800〜34,800円
粗利率: **55〜65%**（高水準）
-5点は「$232という価格をどう訴求するか」の課題（ただしカリステニクス特化コミュニティへは刺さりやすい）。

### **合計スコア: 92/100点** ⭐⭐⭐ 強く推奨

## 製品②：CobraPress（David Barouche / CalfPro）

### 基本情報
| 項目 | 内容 |
|------|------|
| メーカー | David Barouche / CalfPro（米国） |
| プラットフォーム | Kickstarter |
| 発売時期 | 2025年10〜11月 |
| 調達金額 | $78,443（目標$15,000 → 達成率**523%**） |
| 支援者数 | ~678名 |
| 価格帯 | $99〜115（早期〜通常） |
| 円換算 | 約14,400〜16,700円 |
| 重量 | <1kg（電池不要、プラスチック製レバー） |
| Amazon Japan | **未出品**（2025年11月終了、流通前） |
| 日本代理店 | **なし**（確認済） |

### 製品特徴
- **電池・電力不要**の純機械式フルボディマッサージツール
- 「梃子の原理」で身体の自重を利用して深部圧迫マッサージ
- 着脱可能なピラミッド型ヘッドで12の筋肉部位をカバー
- 理学療法士が使う「虚血性圧迫法（Ischemic Compression）」を再現
- 前身製品「CalfPro」で出荷実績あり、製品化・納品リスク低

### 4軸スコアリング

#### 市場需要（**21/25点**）
フィットネス後のリカバリーツール需要は急増中（マッサージガン市場拡大が証拠）。ただし「梃子の原理のマッサージ」という概念が日本語で直感的に伝わりにくい。SNS動画での実演が重要。-4点は認知形成に時間がかかるリスク。

#### 競合状況（**23/25点**）
マッサージガン（Theragun・Hyperice）は競合だが高価。泡ローラー（フォームローラー）は安いが効果が限定的。CobraPressの「道具1本でフルボディの深部圧迫」は競合空白地帯。-2点は泡ローラーとの差別化説明コスト。

#### 法規制適合（**22/25点**）
電力不要の手動マッサージ器具。薬機法の医療機器には該当しない（治療目的の表現を避ければOK）。輸入規制なし。-3点は「体に圧力をかける器具」として広告コピーに注意が必要な点。

#### 価格競争力（**24/25点**）
推定仕入れ価格: $45〜55（約6,500〜8,000円）
想定販売価格: 14,800〜17,800円
粗利率: **60〜70%**（非常に高い）
カジュアルにも手が届く価格帯でギフト需要も見込める。-1点はリピート購入が発生しにくい点。

### **合計スコア: 90/100点** ⭐⭐⭐ 強く推奨

| プラットフォーム | Kickstarter |

| 支援者数 | ~479名 |
| 価格帯 | $89〜133 |
| 円換算 | 約12,900〜19,300円 |
| 重量 | 不明（推定1〜2kg以下） |
| バッテリー | 25.9Wh（PSEマーク取得要件あり） |
| Amazon Japan | **未出品**（CamperKitのみ、Aecooly扇風機は出品あり） |
| 日本代理店 | **なし** |

### 製品特徴
- 本体1台に11以上のモジュールが磁石で着脱
- モジュール: ライト・ランタン・ファン・ウォーターポンプ・エアポンプ・充電器・弧光ライター 等
- 25.9Whバッテリー内蔵のスマートコントローラーが中核
- Kickstarter「Project We Love」バッジ獲得
- 日本のキャンプブーム（ソロキャンプ・グランピング）に適合

### 4軸スコアリング

#### 市場需要（**22/25点**）
日本のキャンプ人口は2020年以降急増し定着。「電源不要で多機能」というモジュール設計は「荷物を減らしたいキャンパー」にドンピシャ。-3点は「モジュール式の複雑さ」が初見では伝わりにくい点。

#### 競合状況（**20/25点**）
多機能ランタン（GOAL ZERO等）や各種キャンプガジェットは競合。ただし「磁石接続モジュール式」という設計は唯一無二。-5点は既存の単機能キャンプガジェットとの訴求比較が必要な点。

#### 法規制適合（**18/25点**）
リチウムイオンバッテリー搭載製品のため**PSEマーク取得が必須**（電気用品安全法）。エアポンプ・ウォーターポンプの電気安全基準も確認要。取得に3〜6ヶ月かかる場合がある。-7点はこの法規制対応コストとリードタイム。

#### 価格競争力（**24/25点**）
推定仕入れ価格: $35〜50（約5,100〜7,300円）
想定販売価格: 13,800〜16,800円
粗利率: **60〜72%**（非常に高い）
-1点は初期PSE取得コストの償却分。

### **合計スコア: 84/100点** ⭐⭐ 推奨（PSE確認後）
