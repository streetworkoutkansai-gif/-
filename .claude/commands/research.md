## このスキルを使うタイミング

以下のキーワードが含まれる依頼はすべてこのスキルで処理する:

- リサーチ・調査・市場調査
- Kickstarter・Indiegogo・Wadiz・Zeczec・クラウドファンディング
- 海外製品・輸入・仕入れ候補
- 展示会・CES・SXSW・欧米製品
- 日本市場適合性・競合・規制

## エージェント起動手順

### 標準リサーチフロー（3フェーズ構成）

```
Phase 1: スクリーニング（Sora）
  → guidelines/07_overseas_research.md を参照
  → 指定カテゴリ・条件でプラットフォームを横断リサーチ
  → 候補20件をリストアップしてファイルに出力
  → output: research/screening_YYYYMMDD.md

Phase 2: 詳細分析（Sora）
  → Phase 1 の出力ファイルを読み込む
  → 上位5件を4軸（需要・競合・規制・価格）でスコアリング
  → output: research/analysis_YYYYMMDD.md

Phase 3: レポート作成（Sora）
  → Phase 2 の出力ファイルを読み込む
  → 推奨仕入れ候補1〜3件をまとめたレポートを作成
  → templates/research_report.md に従って出力
  → Kenji（戦略部門）に提出
```

### 大型タスク時の注意

各フェーズは独立したエージェントとして起動し、フェーズ完了後に出力ファイルを次のフェーズに渡す。
コンテキストリセットにより精度を維持する。

## スコアリング基準（100点満点）

| 軸 | 配点 | 推奨基準 |
|----|------|---------|
| 市場需要 | 25点 | 日本での類似需要・検索ボリューム |
| 競合状況 | 25点 | 空白地帯か・競合の強さ |
| 法規制適合 | 25点 | 薬事法・輸入規制・安全基準 |
| 価格競争力 | 25点 | 仕入れ値・販売価格・利益率 |
| **合計** | **100点** | **70点以上で推奨** |
