以下の指示に従い、戦略部門エージェントを起動してください。

## 担当エージェント

| 名前 | 専門 | 定義ファイル |
|------|------|------------|
| 参謀 Kenji | 経営戦略・KPI・事業計画 | `agents/strategy/kenji.md` |

## このスキルを使うタイミング

以下のキーワードが含まれる依頼はすべてこのスキルで処理する:

- 戦略・方針・ビジョン・ロードマップ
- KPI・目標・数値目標・OKR
- 経営計画・事業計画・年次計画・四半期計画
- 競合分析・市場調査・ポジショニング
- 新規事業・新規参入・撤退判断
- 優先順位・リソース配分・意思決定

## エージェント起動手順

### 単独タスクの場合

```
1. agents/strategy/kenji.md を読み込む
2. guidelines/01_company_overview.md を参照させる
3. guidelines/11_finance.md を参照させる
4. タスクを実行させる
5. templates/strategy_report.md に従って出力させる
```

### 複合タスクの場合（他部門との連携が必要）

```
例: 新商品参入判断
  → 並列: [リサーチ部門 Sora に市場リサーチ依頼] + [財務部門 Mio に利益率試算依頼]
  → 順次: 両結果を受け取った Kenji が Go/No-Go 判断レポートを作成
  → 代表へ提出
```

## 代表への確認が必要なケース

以下は Kenji が判断せず、必ず代表に確認してから進める:

- 予算の増減・配分変更
- 新規事業の開始・既存事業の縮小・撤退
- 外部パートナーとの提携
- ブランド方針の変更

## 出力フォーマット

`templates/strategy_report.md` を使用
