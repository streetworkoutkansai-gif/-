以下のキーワードが含まれる依頼はすべてこのスキルで処理する:

- 売上・収益・利益・損益
- 予算・経費・コスト・費用
- PL・損益計算書・財務・キャッシュフロー
- KPI・CPA・ROI・LTV・CAC
- 仕入れコスト・利益率試算
- 月次レポート・数値まとめ

## エージェント起動手順

### 月次財務レポート作成

```
1. agents/finance/mio.md を読み込む
2. guidelines/11_finance.md を参照
3. 売上・費用・利益を部門別に集計
4. 前月比・予算比を計算
5. templates/weekly_report.md（財務版）に従って出力
6. 戦略部門 Kenji に共有
```

### 利益率シミュレーション（新商品・仕入れ検討時）

```
1. agents/finance/mio.md を読み込む
2. リサーチ部門 Sora から商品情報・仕入れコストを受け取る
3. 以下を試算して出力:
   - 仕入れ単価・送料・関税
   - 想定販売価格・粗利率
   - 損益分岐点（月間販売数）
   - 3ヶ月・6ヶ月・12ヶ月の利益シナリオ（楽観/中立/悲観）
4. 戦略部門 Kenji に提出
```

### 広告費ROI分析

```
1. agents/finance/mio.md を読み込む
2. 広告部門 Mika から広告費・CVデータを受け取る
3. 媒体別ROI・CPA・CTRを集計
4. 費用対効果の低い媒体・改善ポイントを指摘
5. 代表に報告・予算見直し提案（決定は代表）
```

## 重要KPI定義と更新頻度

| KPI | 定義 | 更新頻度 |
|-----|------|---------|
| 月次売上 | ジム会費 + EC売上 合計 | 月次 |
| 粗利率 | (売上 - 仕入れ原価) / 売上 | 月次 |
| 営業利益 | 粗利 - 固定費 - 変動費 | 月次 |
| LTV | 顧客生涯価値（ジム・EC別） | 四半期 |
| CAC | 顧客獲得コスト | 月次 |
| 広告ROI | 広告売上 / 広告費 | 週次 |

## 代表への確認が必要なケース

- 予算配分の変更
- 税務・会計に関する重要判断
- 外部会計士・税理士への相談が必要な事項
