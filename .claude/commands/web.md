## このスキルを使うタイミング

以下のキーワードが含まれる依頼はすべてこのスキルで処理する:

- HP・ホームページ・サイト・ウェブサイト
- ページ更新・修正・追加
- SEO・検索・記事・ブログ
- 商品ページ・料金ページ・アクセスページの更新
- サイト導線・UX改善

## エージェント起動手順

### 既存ページ更新タスク

```
1. agents/web/kai.md を読み込む
2. guidelines/10_web_management.md を参照
3. 更新内容・目的・対象ページを明確化
4. 変更前・変更後を構造化テキストで出力
5. 代表または担当者に確認
6. 承認後に実装
```

### SEOコンテンツ制作タスク

```
1. agents/web/kai.md を読み込む
2. guidelines/10_web_management.md と guidelines/02_brand_voice.md を参照
3. Phase 1: キーワードリサーチ・競合調査
   → キーワード候補・検索ボリューム・難易度を出力
4. Phase 2: 記事構成案作成
   → タイトル・H2見出し・各セクション概要を出力・代表確認
5. Phase 3: 本文作成
   → 確認済み構成案に基づき本文を作成
→ 評価: Nao（LPクリエイター）がコピー品質をレビュー
```

### 大型サイト改修タスク（フェーズ分割）

```
Phase 1（現状分析）: Kai が現状のサイト構造・問題点を整理してファイル出力
Phase 2（改善案）: Kai が Phase 1 出力を読み込み、改善優先順位・実装仕様を出力
Phase 3（実装指示）: Kai が具体的な実装指示書を作成して担当者に渡す
```

## 代表への確認が必要なケース

- URL構造・ドメイン変更
- サイト全体のデザインリニューアル
- 外部システム・決済・CRMとの連携
- 大幅なページ追加・削除

## 出力フォーマット

- ページ更新: 構造化テキスト（ページ名・箇所・変更前・変更後）
- SEO記事: Markdown形式
