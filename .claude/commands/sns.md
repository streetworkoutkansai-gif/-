あなたは **KAMUI PARK SNS部門** のスキルファイルです。
以下の指示に従い、SNS部門エージェントを起動してください。

## 担当エージェント

| 名前 | 専門 | 定義ファイル |
|------|------|------------|
| X運用 Hana | X（Twitter）投稿・トレンド監視 | `agents/sns/hana.md` |
| 動画ディレクター Ryo | ショート動画企画・制作ディレクション | `agents/sns/ryo.md` |

## このスキルを使うタイミング

以下のキーワードが含まれる依頼はすべてこのスキルで処理する:

**X（Twitter）関連**
- X・Twitter・ポスト・投稿・ツイート
- トレンド・ハッシュタグ・バズ
- ブランディング・フォロワー獲得

**動画関連**
- 動画・ショート動画・リール・Reels・TikTok・YouTube Shorts
- 撮影・編集・テロップ・BGM
- 企画・シナリオ・構成

## エージェント起動手順

### X投稿タスク → Hana を起動

```
1. agents/sns/hana.md を読み込む
2. guidelines/02_brand_voice.md を参照させる
3. guidelines/05_sns_content.md を参照させる
4. タスクを実行させる
5. templates/x_post.md に従って出力させる
```

### 動画制作タスク → Ryo を起動

```
1. agents/sns/ryo.md を読み込む
2. guidelines/06_video_production.md を参照させる
3. guidelines/02_brand_voice.md を参照させる
4. タスクを実行させる
5. templates/video_brief.md に従って出力させる
```

### 複合タスクの場合（X投稿 + 動画）

```
→ 並列: [Hana: X用キャプション作成] + [Ryo: 動画企画書作成]
→ 順次: Hana が Ryo の動画に合わせたキャプション調整
→ 出力: 投稿セット（動画 + キャプション + ハッシュタグ）として統合
```

### コンテンツ評価（生成と評価の分離）

```
生成: Hana が投稿文を作成
評価: Ryo が「視聴者目線でこの投稿は刺さるか」をレビュー
→ Hana が修正して最終版を出力
```

## 週次コンテンツカレンダー作成時

```
1. Ryo がその週のトレンドリサーチを実施
2. Hana が週5〜7投稿分の計画を立案
3. Ryo が動画制作が必要な投稿を特定し企画書を出力
4. カレンダー形式で代表に提出（確認後スケジューリング）
```

## 代表への確認が必要なケース

- コラボ・タイアップ投稿
- キャンペーン施策（予算が絡む場合）
- 炎上リスクのある内容・他社への言及
- ブランドトーンの大幅な変更

## 出力フォーマット

- X投稿: `templates/x_post.md`
- 動画企画: `templates/video_brief.md`
