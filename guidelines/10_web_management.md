# KAMUI PARK Webサイト管理マニュアル

> このガイドラインはWebディレクター（Kai）が参照するHP管理・SEOの基本ルールです。

---

## 1. Webサイト管理の基本方針

- サイトに来た人が「迷わず行動できる」状態を常に維持する
- 情報の鮮度を保つ（古い情報はすぐに更新する）
- SEOはユーザーファーストで取り組む（検索エンジンより人間向けに書く）
- 更新前にバックアップ・更新後に動作確認を必ず行う

---

## 2. サイト構成の基本

### ページ優先度

| 優先度 | ページ | 役割 |
|--------|-------|------|
| 最高 | TOPページ | 全体訴求・導線 |
| 最高 | ジム紹介ページ | 体験申し込み誘導 |
| 最高 | 商品一覧・商品詳細 | EC購入誘導 |
| 高 | 料金・プランページ | 入会判断サポート |
| 高 | アクセス・概要ページ | 来館サポート |
| 中 | ブログ・コンテンツ | SEO・信頼構築 |
| 中 | お問い合わせ | 問い合わせ導線 |

---

## 3. ページ更新ルール

### 更新フロー

```
1. 更新依頼を受ける（部門 or 代表から）
2. 更新内容・目的・対象箇所を整理する
3. 変更前・変更後を構造化テキストで出力（確認用）
4. 代表 or 担当者の承認を取る
5. 実装する
6. 更新後に以下を確認:
   □ 表示崩れがないか
   □ リンクが正しく機能しているか
   □ スマートフォン表示の確認
   □ 誤字脱字のチェック
```

### 軽微な更新（確認不要で対応できるもの）

- 営業時間・休業日の変更
- 料金表の数値更新（変更承認後）
- イベント・体験会の日程追加・削除
- 誤字脱字の修正

### 代表確認が必要な更新

- ページ新規作成・削除
- URL構造の変更
- デザインの大幅変更
- 外部連携（フォーム・決済・予約システム）の変更

## 4. SEOコンテンツ制作ルール

### キーワード選定の基準

| 指標 | 基準 |
|------|------|
| 月間検索ボリューム | 100〜10,000（ニッチ語狙い）|
| 競合難易度 | 低〜中（既存コンテンツで上位表示できるか） |
| ビジネス適合性 | 記事からジム・EC誘導ができるか |

### 記事構成の標準フォーマット

```
タイトル（H1）: キーワードを含む・32字以内
  ※ 例: 「カリステニクスとは？初心者が3ヶ月で変わる始め方ガイド」

リード文（200字以内）:
  - 読者の悩みに共感
  - この記事で何が分かるかを明示

H2〜H3 見出し構成:
  - H2: 大テーマ（3〜6個）
  - H3: 各テーマの詳細（2〜4個ずつ）

まとめ:
  - 記事の要点を3行で
  - CTAを自然に入れる（「まずは体験会へ」等）
```

### 内部リンク設計

```
ブログ記事 → 関連商品ページ
ブログ記事 → ジム体験申し込みページ
ブログ記事 → 関連ブログ記事（2〜3本）
商品ページ → 関連商品
商品ページ → 使い方ブログ記事
```

## 5. UX・導線設計の原則

### CTAの配置ルール

| ページタイプ | CTAの位置 |
|-----------|---------|
| TOPページ | ファーストビュー内・中段・フッター前 |
| ジム紹介 | ヒーロー直下・各セクション後・フッター前 |
| 商品ページ | ファーストビュー内・説明後・フッター前 |
| ブログ記事 | リード文後・本文中段・記事末尾 |

### モバイルファースト原則

- スマートフォンでの表示・操作性を最優先で確認する
- フォント: 最小16px以上
- タップ領域: 44px × 44px以上
- スクロールなしで重要情報が見えるか確認する
