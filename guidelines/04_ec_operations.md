# KAMUI PARK EC・物販運営マニュアル

> このガイドラインはEC部門・リサーチ部門・財務部門が参照する物販事業の基本ルールです。

---

## 1. EC事業の基本方針

- カリステニクス専門店としての信頼性を最優先にする
- 「自分が使いたいと思う商品だけを売る」という姿勢を崩さない
- 誇大広告・根拠のない効果訴求は一切行わない
- 顧客の期待値を上回る品質・サービスを提供する

---

## 2. 商品選定基準

### 仕入れ判断の4軸

| 軸 | チェック内容 |
|----|------------|
| 専門性適合 | カリステニクス・自体重トレーニングに関連するか |
| 品質水準 | 使用に耐える品質か（代表が実際に使えるか） |
| 市場適合 | 日本のターゲット顧客が必要としているか |
| 収益性 | 粗利率30%以上を確保できるか |

### 仕入れ禁止カテゴリ

- 薬事法に抵触する可能性のある製品
- 安全性が未確認の製品
- カリステニクスと無関係な製品

---

## 3. 商品ページ制作ルール

### 必須記載項目

```
1. 商品名（SEOキーワードを含む）
2. 商品画像（メイン1枚 + サブ3枚以上）
3. 価格（税込表示）
4. 商品説明（特徴・用途・対象者）
5. スペック・サイズ表
6. 使い方・注意事項
7. 発送・返品ポリシー
8. レビュー（実績がある場合）
```

### コピーライティング原則

- キャッチ: ターゲットの「欲しい」「解決したい」を一言で表す
- ボディ: 特徴を「機能」でなく「体験・効果」で伝える
- CTA: 「カートに入れる」ではなく、何が起きるかを示す表現も検討

---

## 4. 注文処理フロー

```
1. 注文受付（ECプラットフォーム通知）
2. 在庫確認
3. 梱包・発送手配
4. 発送完了通知（顧客への自動メール）
5. 届いたか確認（3〜5日後のフォローメッセージ）
6. レビュー依頼（受け取り確認後）
```

---

## 5. 価格設定ルール

| 項目 | 基準 |
|------|------|
| 最低粗利率 | 30%以上 |
| 推奨粗利率 | 40〜50% |
| 価格改定 | 代表確認必須 |

### 利益率計算式

```
粗利率 = (販売価格 - 仕入れ原価 - 梱包費 - 送料) / 販売価格 × 100
```

---

## 6. 在庫管理ルール

| 状態 | 対応 |
|------|------|
| 残10個以下 | 補充検討・代表に報告 |
| 残0個（在庫切れ） | 即時販売停止・入荷予定表示 |
| 長期在庫（3ヶ月以上売れない） | 値下げ・販売終了を代表に提案 |

---

## 7. 顧客対応基本方針

- 問い合わせには24時間以内に返信する
- 返品・交換は購入後14日以内・未開封を原則とする（詳細は返品ポリシーに従う）
- クレームは事実確認を先に行い、感情的にならず解決策を先に提示する
- 顧客の氏名・住所・注文情報は厳重に管理し、外部に漏洩させない

---

## 8. KPI管理

| KPI | 定義 | 計測頻度 |
|-----|------|---------|
| 月次EC売上 | EC全体の合計売上 | 月次 |
| 商品別売上 | 各商品の売上順位 | 月次 |
| 転換率（CVR） | 商品PV数 / 購入数 | 週次 |
| 平均注文単価 | 総売上 / 注文数 | 月次 |
| 返品率 | 返品数 / 注文数 | 月次 |
| リピート率 | 2回以上購入者数 / 総顧客数 | 四半期 |
