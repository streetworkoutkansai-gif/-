# KAMUI PARK カスタマーサービスマニュアル

> このガイドラインはジム部門（Taro）・CRM専門家（Tomo）が参照する顧客対応の基本ルールです。

---

## 1. 顧客対応の基本方針

- すべてのお客様を「カリステニクスの仲間」として接する
- 問題解決を最優先にする（責任の所在を先に問わない）
- 迅速・誠実・具体的な対応を徹底する
- 対応の品質は代表が直接見ていると思って行動する

---

## 2. 対応チャネルと目標応答時間

| チャネル | 目標応答時間 | 備考 |
|---------|-----------|------|
| LINE（L-STEP） | 自動応答即時 / 有人対応24時間以内 | 24時間受付 |
| メール | 24時間以内 | 平日のみ（休日は翌営業日） |
| DM（X/Instagram） | 48時間以内 | — |
| 電話 | 営業時間内即時 | 不在時は折り返し |
| 対面（ジム受付） | 即時 | — |

---

## 3. お客様対応の黄金フロー

```
Step 1: 傾聴・確認
  → お客様の話を最後まで聞く（遮らない）
  → 「〇〇ということでしょうか？」と確認する

Step 2: 共感・謝罪（必要な場合）
  → 「ご不便をおかけして申し訳ございません」
  → 事実確認前でも「不快な思いをさせた」ことへの謝罪は行う

Step 3: 事実確認
  → 何が・いつ・どのように起きたかを整理する
  → 感情的な言葉には乗らず、事実だけを確認する

Step 4: 解決策の提示
  → 2〜3つの解決策を具体的に提示する
  → お客様に選んでいただく形にする

Step 5: フォローアップ
  → 対応後3〜5日以内に「その後いかがですか？」の確認連絡を行う
```

## 5. クレーム対応禁止事項

```
× 「でも」「しかし」「ただ」で言い訳をする
× お客様の感情を否定する（「それは誤解です」等）
× 他者への責任転嫁（「配送業者のミスで」等の第一声）
× 返答を曖昧にする（「検討します」「前向きに」等でごまかす）
× 感情的になる・口論になる
```

---

## 6. エスカレーション基準

以下の場合は即座に代表に報告・判断を仰ぐ:

```
□ 返金・補償・割引の要求
□ 法的手段・弁護士・SNS拡散等の言及
□ 安全・健康に関わる重大な問題
□ 複数顧客からの同一クレーム（品質問題の可能性）
□ メディア・インフルエンサーからの問い合わせ
```

---

## 7. 感謝・ポジティブメッセージへの対応

お客様からの嬉しいメッセージ・口コミには必ず返信する。

```
「ありがとうございます！そのお言葉がとても励みになります。
〇〇さんが〇〇できたと聞いて、私たちも嬉しいです。
引き続き一緒に成長していきましょう！」
```

ポジティブな口コミはスクリーンショットして代表に共有し、
SNSや証拠コンテンツとして活用できないか確認する。
