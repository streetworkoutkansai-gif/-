# KAMUI PARK CRM・メールコミュニケーションマニュアル

> このガイドラインはCRM専門家（Tomo）が参照するL-STEP・メール・ステップメールの基本ルールです。

---

## 1. CRMの基本方針

- 「適切な人に、適切なタイミングで、適切なメッセージ」を届ける
- 一方的な配信ではなく、顧客の状態・行動に応じた対話型設計にする
- 売り込みより価値提供を先行させる（信頼→関係→購買の順）
- 開封率・クリック率を定期的に計測し改善し続ける

---

## 2. 顧客状態の定義

| 状態 | 説明 | 優先アクション |
|------|------|--------------|
| 新規登録 | LINE・メール登録直後 | 歓迎・期待醸成 |
| 興味期 | コンテンツを読んでいるが未購入 | 価値提供・信頼構築 |
| 検討期 | LP閲覧・カート投入済み | 背中押し・FAQ解消 |
| 購入後（初回） | 初回購入・入会後 | 使い方・活用サポート |
| リピーター | 2回以上購入・継続会員 | 深化・アップセル |
| 離脱危険 | 最終購入・来館から90日以上 | 再エンゲージ |

## 3. L-STEPシナリオ設計ルール

### 基本構成（ジム体験予約者向け例）

```
Day 0（登録直後）
  → 「ご予約ありがとうございます！当日の流れをお伝えします」
  → 体験当日の準備・服装・アクセスを案内

Day 1（前日）
  → 「明日お待ちしています！こんなことを体験できます」
  → 期待感を高める内容

Day 0（当日終了後）
  → 「今日はありがとうございました！」
  → 感想ヒアリング + 入会案内

Day 3（3日後、未入会者のみ）
  → 「体験後どうでしたか？」
  → 入会を迷っている方向けのFAQ + 背中押し

Day 7（1週間後、まだ未入会）
  → 「一緒に始めた方の声をお届けします」
  → 社会的証明 + 期間限定特典（ある場合）
```

### 分岐条件の設定方法

```
タップあり → より深い情報へ進める
タップなし → 別角度のコンテンツを送る
購入済み → 購入者向けシナリオに切り替える
未購入 → 継続フォロー or 再エンゲージシナリオへ
```

## 4. メール文章の書き方ルール

### 件名の重要性

件名で開封率が決まる。以下の型を使う:

| 型 | 例 |
|----|-----|
| 数字型 | 「3つのよくある間違い（カリステニクス初心者向け）」 |
| 疑問型 | 「プルアップが上達しない本当の理由、知っていますか？」 |
| 個人型 | 「〇〇さんへ、体験会の翌日に読んでほしい話」 |
| 緊急型 | 「明日18時終了: 体験会の残り2枠について」 |

### 本文の構成

```
1行目: 要件を一言で（「先日の体験会のお礼です」等）
2〜4行: 相手の状況を想像した導入（共感・つなぎ）
5行〜: 本題（具体的な価値・情報・提案）
最終行: 1つだけCTA（複数入れない）
P.S.: 読者が一番読むので、重要なサブメッセージを入れる
```

### 1通1メッセージの原則

1通のメールに「伝えたいこと」を1つだけにする。
複数入れると何もしてもらえなくなる。

## 5. クレーム・問い合わせ対応フロー

### 分類と対応方針

| 分類 | 初動対応 | 目標解決時間 |
|------|---------|-----------|
| 一般問い合わせ | 確認→回答 | 24時間以内 |
| 注文・配送トラブル | 事実確認→状況説明 | 12時間以内 |
| クレーム・不満 | 謝罪→原因確認→解決策 | 6時間以内（受付のみでも） |
| 返品・交換希望 | ポリシー確認→案内 | 24時間以内 |

### クレーム対応の鉄則

```
1. まず謝罪（事実確認前でも「ご不便をおかけして...」は言える）
2. 感情的にならない・言い訳しない
3. 事実を確認する（何がいつ起きたか）
4. 解決策を2〜3案提示して選んでもらう
5. 再発防止策をセットで伝える
6. フォローアップ（解決後に確認連絡）
```

## 6. 計測すべき指標

| 指標 | 良好水準 | 要改善水準 |
|------|---------|----------|
| メール開封率 | 25%以上 | 15%未満 |
| クリック率 | 3%以上 | 1%未満 |
| LINE既読率 | 60%以上 | 40%未満 |
| LINEクリック率 | 15%以上 | 5%未満 |
| 配信解除率 | 0.5%未満 | 2%以上（要改善） |
