# KAMUI PARK 動画制作マニュアル

> このガイドラインは動画ディレクター（Ryo）が参照する動画制作の標準フローです。

---

## 1. 動画制作の基本方針

- 「見た人が何かを得られる」コンテンツを最優先にする
- バズを目的にせず、ブランド価値と情報価値の両立を目指す
- 各プラットフォームのネイティブフォーマットに最適化する
- 毎週トレンドをリサーチし、フォーマットをアップデートし続ける

---

## 2. プラットフォーム別仕様

| 項目 | TikTok | Instagram Reels | YouTube Shorts |
|------|--------|----------------|---------------|
| 推奨サイズ | 9:16 縦型 | 9:16 縦型 | 9:16 縦型 |
| 解像度 | 1080×1920 | 1080×1920 | 1080×1920 |
| 推奨時間 | 15〜60秒 | 15〜90秒 | 15〜60秒 |
| テキスト安全圏 | 上下15%を避ける | 上下15%を避ける | 上下20%を避ける |
| 音楽 | トレンド音源OK | トレンド音源OK | 著作権フリーのみ |

---

## 3. トレンドリサーチの方法

### 週次リサーチ（毎週月曜日）

```
1. TikTok・Reelsのトレンドサウンド上位20曲を確認
2. カリステニクス・フィットネスカテゴリの上位10動画を分析
3. 分析観点:
   - 動画の長さと構成（何秒で何を見せているか）
   - テロップのスタイル（フォント・サイズ・タイミング）
   - BGM（テンポ・ジャンル）
   - 最初の3秒の見せ方
   - CTA（最後にどう誘導しているか）
4. 今週取り入れるフォーマットを1つ選定して企画に反映
```

## 4. バズる動画の構成パターン

### パターンA: 「知らなかった」型
```
[0秒] フック: 「プルアップできない人が全員やってる間違い」
[5秒] 問題提示: よくあるNG例を見せる
[20秒] 解決策: 正しいやり方を実演
[45秒] まとめ: 一言で結論
[55秒] CTA: 「プロフのリンクから詳細」
```

### パターンB: 「変化」型
```
[0秒] フック: 「90日前→今日の体」
[3秒] ビフォー映像
[20秒] トレーニングシーン
[40秒] アフター映像
[50秒] 「詳しい方法はこちら」
```

### パターンC: 「タメになる豆知識」型
```
[0秒] 「筋トレしてる人が知らない事実」
[5秒] 豆知識1
[20秒] 豆知識2
[35秒] 豆知識3
[50秒] 「もっと知りたい人は→」
```

## 5. 撮影ディレクション指示書の書き方

### 必須記載項目

```
1. 動画タイトル・目的
2. 使用プラットフォーム
3. 時間（秒数）
4. 構成・カット割り（各カットの秒数・映像内容）
5. テロップ内容・タイミング
6. BGM指示（テンポ・雰囲気・候補曲）
7. ロケ指示（場所・背景・照明）
8. 出演者・衣装
9. NGカット・注意点
```

---

## 6. テロップ制作ルール

| 項目 | ルール |
|------|--------|
| フォントサイズ | 画面の10〜15%の高さ |
| 文字数 | 1テロップ10〜20字以内 |
| 表示時間 | 1秒あたり4〜6字が読みやすい基準 |
| 色 | 白文字 + 黒縁 または 黒文字 + 白背景 |
| 強調 | 重要語句は色を変える（黄・赤等） |

---

## 7. 動画公開設定チェックリスト

```
□ タイトルにキーワードが入っているか
□ サムネイルは目立つか・テキストが読めるか
□ 説明文にリンクが貼られているか
□ ハッシュタグは適切か（3〜5個）
□ 公開タイミングは最適か（TikTok: 19〜22時 / Reels: 12〜13時・21〜22時）
□ 他プラットフォームへのクロスポスト設定
```

---

## 8. パフォーマンス分析（週次）

| 指標 | 確認内容 |
|------|---------|
| 視聴完了率 | 何%が最後まで見ているか（目標: 30%以上） |
| いいね率 | 視聴者に対するいいね数 |
| シェア・保存率 | 「また見たい」「誰かに見せたい」の指標 |
| フォロワー転換率 | 動画経由でのフォロワー増加数 |

分析結果は次の企画に必ず反映する。
