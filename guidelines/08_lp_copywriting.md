# KAMUI PARK LP・コピーライティングマニュアル

> このガイドラインはLPクリエイター（Nao）・広告クリエイター（Mika）が参照するコピーの基本ルールです。

---

## 1. コピーライティングの基本原則

### 大前提: 読者は「自分のことしか考えていない」

読者はKAMUI PARKのことに興味がない。
自分の悩みが解決されるか・自分の欲求が満たされるかだけに関心がある。
すべてのコピーはこの前提から逆算して書く。

### 黄金のコピー構造: PASONA

```
P = Problem（問題を明確にする）
  「こんな悩みありませんか？」

A = Agitation（問題をかき混ぜる）
  「このまま放置すると...」

So = Solution（解決策を提示する）
  「そんな悩みを解決するのが...」

O = Offer（具体的な提案をする）
  「今なら〇〇プレゼント...」

N = Narrowing（対象を絞る）
  「本気で変わりたい方だけ...」

A = Action（行動を促す）
  「今すぐ申し込む」
```

## 2. LP構成の標準フレームワーク

### 各セクションの役割

| セクション | 目的 | KPI |
|----------|------|-----|
| ①ヒーロー（ファーストビュー） | 3秒で「これは自分のためのページだ」と思わせる | 離脱率 |
| ②課題・共感 | 読者の悩みを言語化し「分かってくれている」と感じさせる | スクロール率 |
| ③解決策・コンセプト | 「だからKAMUI PARKが必要」を論理的に伝える | 理解度 |
| ④証拠・実績 | 信頼性を高める（数字・お客様の声・実績） | 信頼構築 |
| ⑤詳細・スペック | 検討者の疑問を先回りして解消する | 離脱防止 |
| ⑥FAQ | 不安・懸念を解消する | 購入障壁低減 |
| ⑦CTA | 次の行動を明確に促す | CVR |

## 3. キャッチコピーの書き方

### 3つの型

**型1: 数字型**
```
「3ヶ月で体の使い方が変わる、カリステニクス入門プログラム」
→ 具体的な期間・変化を数字で示す
```

**型2: 問いかけ型**
```
「プルアップが10回できたら、何が変わると思いますか？」
→ 読者を主語にした問い
```

**型3: 逆説型**
```
「道具も器械も要らない。自分の体だけで最強になる方法。」
→ 常識への反論・意外性
```

### キャッチコピーのチェックリスト

```
□ ターゲットが「自分のことだ」と感じるか
□ 具体的な数字・期間が入っているか（入れられる場合）
□ ブランドの差別化が伝わるか
□ 読んで3秒以内に意味が分かるか
□ 誇大表現・根拠のない断言になっていないか
```

## 4. CTAコピーの書き方

### NGパターン vs OKパターン

| NG | OK | 理由 |
|----|----|----|
| 「購入する」 | 「カリステニクスを始める」 | 行動後の未来を示す |
| 「送信する」 | 「無料で体験会を予約する」 | 何が起きるかを明示 |
| 「詳細はこちら」 | 「プログラムの全内容を見る」 | 具体性がある |

---

## 5. 禁止表現一覧

| 禁止表現 | 理由 | 代替表現例 |
|--------|------|----------|
| 「絶対に」「必ず」 | 断言は誇大広告リスク | 「多くの方が」「〇〇した方の声」 |
| 「最高・最強・業界No.1」 | 根拠のない比較 | 「カリステニクス専門」「専門特化型」 |
| 「簡単に」「ラクに」 | ミッションと矛盾・誤解を招く | 「正しい方法で」「段階的に」 |
| 「今すぐ！期間限定！」の多用 | 安売り感・ブランド毀損 | 必要な場合のみ使用・根拠を明記 |

## 6. ターゲットの言葉を使う原則

コピーライターが考えた言葉ではなく、**ターゲットが実際に使う言葉**で書く。

### ターゲットの言葉を集める方法

```
1. 既存顧客へのインタビュー・アンケート
2. SNSの口コミ・コメント
3. Googleサジェスト（「カリステニクス ○○」で何が出るか）
4. Yahoo!知恵袋・Redditの質問内容
5. Amazon商品レビュー（競合商品のレビューを読む）
```

集めた言葉を直接コピーに使うのが最強のコピーライティング。
