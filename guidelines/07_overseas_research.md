# KAMUI PARK 海外製品リサーチマニュアル

> このガイドラインはリサーチ部門エージェント（Sora）が参照するリサーチの標準手順です。

---

## 1. リサーチの基本方針

- 「面白そう」だけでなく「日本で売れるか」を基準に評価する
- データと市場感覚の両方で判断する（スコアリングを必ず使う）
- 規制・法律面のグレーゾーンは必ず代表に確認してから進む
- フェーズを分けて精度を保つ（広く→絞る→深掘り）

---

## 2. リサーチ対象プラットフォーム

| プラットフォーム | URL | 特徴 | 調査頻度 |
|----------------|-----|------|---------|
| Kickstarter | kickstarter.com | 米国発・ガジェット・ライフスタイル強 | 週次 |
| Indiegogo | indiegogo.com | 多様なジャンル・In Demand掲載品多い | 週次 |
| Wadiz | wadiz.kr | 韓国発・K-スポーツ・機能性グッズ | 月次 |
| Zeczec | zeczec.com | 台湾発・デザイン系・アジア感覚 | 月次 |
| 展示会リサーチ | 各展示会公式 | CES・ISPO・Fibo等の出展製品 | 展示会開催時 |

## 3. スクリーニング基準（Phase 1）

### 対象カテゴリ

優先度高:
- トレーニング器具（カリステニクス関連）
- リカバリー・コンディショニングツール
- ウェア・シューズ（機能性特化）
- ニュートリション・サプリ（薬事法注意）

優先度低（対象外に近い）:
- 食品・医薬品
- カリステニクスと無関係なガジェット

### スクリーニング最低ライン

```
Kickstarter/Indiegogo:
  □ 調達金額: $10,000以上
  □ 支援者数: 100人以上
  □ 残り日数: 7日以上（進行中の場合）
  □ カテゴリ適合: カリステニクス・フィットネス関連

Wadiz/Zeczec:
  □ 調達金額: ₩5,000,000以上 / NT$100,000以上相当
  □ 支援者数: 50人以上
```

## 4. 詳細分析スコアリング（Phase 2）

### 4軸100点満点

#### 軸1: 市場需要（25点）

| スコア | 基準 |
|--------|------|
| 25点 | 国内Google検索ボリューム1,000以上 / SNSでの言及多数 |
| 15〜24点 | 関連需要はあるが直接的な需要は少ない |
| 5〜14点 | 需要は存在するが小さい |
| 0〜4点 | 日本での需要がほぼ見当たらない |

#### 軸2: 競合状況（25点）

| スコア | 基準 |
|--------|------|
| 25点 | 直接競合なし・カテゴリ空白あり |
| 15〜24点 | 競合は存在するが差別化できる |
| 5〜14点 | 強い競合が複数存在する |
| 0〜4点 | 価格・品質で競合に勝てない |

#### 軸3: 法規制適合（25点）

| スコア | 基準 |
|--------|------|
| 25点 | 規制なし・輸入手続きが明確 |
| 15〜24点 | 軽微な手続きが必要だが問題なし |
| 5〜14点 | PSEマーク・技適等が必要で手間がかかる |
| 0〜4点 | 薬事法・輸入規制に抵触リスク |

#### 軸4: 価格競争力（25点）

| スコア | 基準 |
|--------|------|
| 25点 | 粗利率50%以上 |
| 15〜24点 | 粗利率40〜49% |
| 5〜14点 | 粗利率30〜39% |
| 0〜4点 | 粗利率30%未満（仕入れコストが高すぎる） |

**推奨基準: 70点以上**

## 5. レポート作成（Phase 3）

`templates/research_report.md` を使用。
提出先: 戦略部門 Kenji → 代表へエスカレーション。

### 必ず記載する項目

```
1. エグゼクティブサマリー（3行以内）
2. 候補製品一覧（スコア順）
3. 推奨製品の詳細分析
4. 想定仕入れ価格・販売価格・利益率
5. リスク・懸念事項
6. 推奨アクション（次のステップ）
```

## 6. 仕入れ候補ランク定義

| ランク | スコア | 推奨アクション |
|--------|--------|--------------|
| A | 85〜100点 | 即座に代表に提案・優先検討 |
| B | 70〜84点 | 次の仕入れサイクルで検討 |
| C | 50〜69点 | 経過観察・市場変化次第で再評価 |
| D | 49点以下 | 今サイクルは見送り |
