# KAMUI PARK ジム運営マニュアル

> このガイドラインはジム部門エージェント（Taro）が参照する運営の基本ルールです。

---

## 1. ジムの基本方針

- カリステニクス専門ジムとして「正しい動作習得」を最優先にする
- 会員一人ひとりのレベルと目標に合わせた対応を行う
- 安全性を犠牲にした無理なプログラムは行わない
- 会員同士が互いに高め合えるコミュニティを育てる

---

## 2. 会員管理

### 会員ステータス定義

| ステータス | 定義 |
|---------|------|
| 体験 | 体験来館のみ。まだ入会していない |
| 新規 | 入会から3ヶ月未満 |
| 継続 | 入会から3ヶ月以上 |
| 休会 | 一時的に利用を停止中 |
| 退会 | 解約済み |

### 入会フロー

```
1. 問い合わせ・体験予約（HP/SNS/LINE）
2. 体験来館（施設見学 + 無料体験レッスン）
3. 入会説明（料金・プラン・ルール説明）
4. 入会手続き（フォーム入力・決済設定）
5. 入会後フォロー（LINEシナリオ・初回レッスン案内）
```

### 退会・休会フロー

```
1. 退会・休会の申し出を受ける
2. 理由を丁寧にヒアリング（解決できる理由なら代替案を提示）
3. 手続き完了
4. 退会者データを記録（理由・在籍期間・利用状況）
5. 退会後フォロー（1ヶ月後に復帰案内を検討）
```

## 3. 月次モニタリング指標

| 指標 | 計算方法 | 目標水準 |
|------|---------|---------|
| 入会数 | 当月新規入会者数 | 毎月設定 |
| 退会数 | 当月退会者数 | — |
| 純増 | 入会数 - 退会数 | プラス維持 |
| 継続率 | (月末会員数 / 月初会員数) × 100 | 95%以上 |
| 体験転換率 | 入会数 / 体験者数 | 30%以上 |

## 4. トレーニングプログラム設計

### レベル定義

| レベル | 対象 | 習得目標 |
|-------|------|---------|
| 入門（Lv.1） | 運動経験ほぼなし〜3ヶ月 | 基礎体力・正しいフォーム習得 |
| 初級（Lv.2） | 3〜12ヶ月 | 基本動作（プッシュアップ・プルアップ・スクワット）完成 |
| 中級（Lv.3） | 1年以上 | 複合動作・スキルムーブ入門（マッスルアップ等） |
| 上級（Lv.4） | 専門的に取り組む会員 | フリースタイル・高難度スキル |

### プログラム設計の原則

1. **段階的過負荷の原則** — 少しずつ負荷を上げる
2. **フォーム優先の原則** — 正しいフォームでできる重量・回数から始める
3. **回復の原則** — 同一筋群は48時間以上空ける
4. **継続性の原則** — 週2〜3回を3ヶ月以上継続できる強度に設定

### 次レベルへの昇格基準

```
Lv.1 → Lv.2:
  プッシュアップ 15回 × 3セット（正しいフォームで）
  スクワット 20回 × 3セット
  ハンギング 30秒以上

Lv.2 → Lv.3:
  プルアップ 10回 × 3セット
  ディップス 15回 × 3セット
  L-sit 10秒以上

Lv.3 → Lv.4:
  マッスルアップ 5回以上
  フロントレバー 5秒以上
  ハンドスタンド 10秒以上
```

## 5. 体験会・イベント設計

### 体験会の標準構成（60分）

```
00:00 - 05:00  受付・アイスブレイク
05:00 - 15:00  カリステニクス概要説明（KAMUI PARKの特徴含む）
15:00 - 40:00  体験レッスン（基礎動作3〜4種目）
40:00 - 50:00  個別目標ヒアリング・質疑応答
50:00 - 60:00  入会案内・施設案内
```

### イベント企画チェックリスト

```
□ 目的（集客 / 既存会員満足度 / コミュニティ強化）
□ 対象（新規体験者 / 会員限定 / 一般公開）
□ 日時・場所・定員
□ 料金（無料 / 有料）
□ 集客方法（SNS / LINE / HP）
□ 当日スタッフ配置
□ 効果測定方法（参加者数・転換率）
```

## 6. 施設管理

### 日次チェックリスト

```
□ 開館前: 施設・器具の点検（破損・劣化確認）
□ 開館前: 清掃確認（床・トイレ・更衣室）
□ 営業中: 使用後の器具消毒・整理整頓
□ 閉館後: 施設全体の清掃・施錠確認
```

### 器具交換基準

| 状態 | 対応 |
|------|------|
| 目視で破損確認 | 即時使用禁止・代表に報告 |
| 劣化が見られる | 1週間以内に代表に報告・交換手配 |
| 通常使用 | 年1回の定期点検 |
