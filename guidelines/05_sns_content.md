# KAMUI PARK SNSコンテンツ戦略マニュアル

> このガイドラインはSNS部門・EC部門が参照するコンテンツ戦略の基本ルールです。

---

## 1. SNS戦略の全体方針

**目的の3層構造:**

```
Layer 1: ブランディング（認知・信頼構築）
  → カリステニクス専門家としての地位確立

Layer 2: コミュニティ育成（エンゲージメント）
  → フォロワーとの関係性深化・ファン化

Layer 3: 収益化（集客・販売）
  → ジム体験会申し込み・EC購入
```

**投稿比率の目安: 6:2:2（価値提供:集客:販売）**

## 2. X（Twitter）運用ルール

### 投稿頻度と時間帯

| 曜日 | 投稿数 | 推奨時間帯 |
|------|-------|----------|
| 平日 | 1〜2投稿 | 7:00〜8:00 / 12:00〜13:00 / 21:00〜22:00 |
| 週末 | 1投稿 | 9:00〜11:00 |

### 投稿分類と目的

| 分類 | 内容 | 目的 |
|------|------|------|
| 知識・Tips | 「〇〇の正しいやり方」「カリステニクス豆知識」 | フォロワー獲得・保存数増加 |
| 共感・エピソード | 「初心者あるある」「続けた結果」 | RT・いいね増加 |
| 製品紹介 | 「これ使ってみた」自然な紹介 | EC誘導 |
| ジム告知 | 体験会・イベント情報 | 集客 |
| 質問投稿 | 「どっちが好き？」「悩みは何？」 | エンゲージメント獲得 |

### ハッシュタグルール

```
必須タグ（常に入れる）: #カリステニクス #KAMUIPARK
カテゴリタグ（内容に応じて2〜3個）:
  トレーニング系: #筋トレ #自重トレーニング #体重トレーニング
  ライフスタイル系: #フィットネス #健康 #毎日の習慣
  商品紹介時: #おすすめグッズ #トレーニンググッズ
合計ハッシュタグ: 3〜5個（多すぎはスパム認定のリスク）
```

## 3. Instagram運用ルール

### フィード投稿

- 画像: 正方形（1:1）または縦長（4:5）統一
- 色調: ブランドカラーに統一（ダーク系・力強さ）
- キャプション: 最初の2行が命。続きを読ませる書き出しにする

### Reels

- 長さ: 15〜60秒がメイン（TikTok同尺で制作可）
- 最初の3秒で「これは見る価値がある」と思わせる
- テロップ必須（音なし視聴者への対応）

## 4. コンテンツカレンダーの作成方法

### 月初の計画フロー

```
1. 月のテーマを決める（例: 「プルアップ強化月間」）
2. その月の告知予定（イベント・商品ローンチ）をリストアップ
3. 週ごとにコンテンツ種類をバランス配分
4. 30件の投稿案をリストアップ（ストック作成）
5. 代表確認 → スケジューリング
```

### 週次レビュー

```
月曜日: 先週のエンゲージメント数値確認
       → 高パフォーマンス投稿の分析（何がよかったか）
       → 今週の計画に反映
```

## 5. 炎上リスク管理

### 投稿前チェックリスト

```
□ 特定個人・他社を批判・揶揄していないか
□ 根拠のない健康効果を謳っていないか
□ 政治・宗教・社会問題に関わる内容ではないか
□ 著作権・肖像権を侵害していないか
□ 炎上しても代表が堂々と立てる内容か
```

### 炎上時の対応フロー

```
1. 即時投稿を削除（迷う場合は先に削除・後で判断）
2. 代表に即報告
3. 反論・弁解はせず、事実確認を先に行う
4. 必要に応じてお詫び投稿
5. 再発防止策を記録
```

## 6. エンゲージメント数値の見方

| 指標 | 良好な水準 | 改善が必要な水準 |
|------|----------|---------------|
| いいね率 | 3%以上 | 1%未満 |
| RT率 | 1%以上 | 0.3%未満 |
| 返信数 | 投稿の5%以上 | ほぼゼロ |
| 保存率（Instagram） | 2%以上 | 0.5%未満 |

※数値はフォロワー数・ジャンルによって異なるため、前月比でのトレンド改善を重視する
