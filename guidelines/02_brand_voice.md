# KAMUI PARK ブランドボイス・トーンガイド

> このガイドラインは、すべてのコンテンツ・コミュニケーションの「声」を統一するためのものです。
> SNS投稿・LP・メール・動画・HPのすべてに適用してください。

---

## 1. ブランドパーソナリティ

KAMUI PARKを「一人の人間」として表現すると:

| 属性 | 内容 |
|------|------|
| 年齢感 | 30代前半 |
| 性格 | 熱くて誠実。知識があるがぽかぽかしている |
| 話し方 | テンポよく・具体的・正直 |
| 印象 | 「この人の言うことは信頼できる」 |

---

## 2. トーン設定（状況別）

### SNS（X・TikTok・Instagram）
- テンポよく、短く、刺さる
- 「あなたも同じじゃないですか？」と問いかける感覚
- 知識は惜しみなく・プロモは自然に
- 絵文字: 控えめに（1投稿1〜2個まで）

### LP・広告
- 読者の痛みと欲求に深く共感する
- 論理的な流れで「だからこそ必要」と導く
- 過度な煽りや誇大表現は一切しない
- CTAは押しつけでなく「次の一歩」として提示

### メール・L-STEP
- 「親しい先輩」のような距離感
- 要点は先に・理由は後で
- 1通1メッセージ（あれもこれも詰め込まない）
- 読んで3秒で「何をしてほしいか」が分かる

### HP・SEO記事
- 丁寧だが堅すぎない
- 専門用語は使うが、必ず平易な言葉で補足する
- ユーザーが「知りたいこと」に素直に答える

---

## 3. 使う言葉・使わない言葉

### 積極的に使う言葉

| 言葉 | 理由 |
|------|------|
| 「成長」「上達」「変化」 | ミッションと直結 |
| 「カリステニクス」 | 専門ブランドの核 |
| 「自体重」「自分の体一つで」 | 差別化・シンプルさの表現 |
| 「毎日」「習慣」 | 継続の大切さを強調 |
| 「一緒に」「あなたと」 | コミュニティ感・寄り添い |

### 使わない言葉・表現

| NG表現 | 理由 |
|--------|------|
| 「絶対に」「必ず」「100%」 | 誇大表現・信頼損失リスク |
| 「今すぐ買わないと損！」系の煽り | ブランドイメージの毀損 |
| 「他社と比べて圧倒的に」「業界最高」 | 根拠のない比較 |
| 専門用語の無説明使用 | 読者の理解を妨げる |
| 過度な草（笑笑笑）・若者言葉 | ターゲット層との乖離 |

## 4. 文章の書き方ルール

### 基本原則

1. **結論を先に** — 何が言いたいか最初の1文で伝える
2. **一文を短く** — 1文40字以内を目標に
3. **体言止めを活用** — リズムが生まれる
4. **読点で改行** — SNSは特に読みやすさ優先

### SNS文章のチェックリスト

```
□ 最初の1〜2行で「続きを読みたい」と思わせているか
□ 具体的な数字・事例が入っているか
□ 読者が「自分のことだ」と感じられる表現になっているか
□ CTAが自然に入っているか（押し付けになっていないか）
□ 140字に収めているか（Xの場合）
```

| 要素 | 方針 |

## 6. NG事例と改善例

### 事例1: LP
- NG: 「このプログラムで絶対に理想の体になれます！」
- OK: 「3ヶ月で体の使い方が変わる、カリステニクス入門プログラム」

### 事例2: X投稿
- NG: 「弊社の商品は業界最高品質です！今すぐご購入を！」
- OK: 「1年使ったけど全然壊れない。これが本物のクオリティ。リンクは↓」

### 事例3: メール
- NG: 「お客様各位、この度は〜（略）〜ご検討いただけますと幸いでございます。」
- OK: 「こんにちは、KAMUI PARKです。先日ご購入ありがとうございました。使い心地はいかがですか？」
