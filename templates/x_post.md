# X（Twitter）投稿テンプレート

> 担当: X運用スペシャリスト Hana
> 参照: guidelines/05_sns_content.md / guidelines/02_brand_voice.md

---

## 出力フォーマット

```
【投稿日時】YYYY/MM/DD HH:MM

【投稿分類】
□ 知識・Tips  □ 共感・エピソード  □ 製品紹介  □ ジム告知  □ 質問

【目的】
（フォロワー獲得 / RT狙い / EC誘導 / 集客 / エンゲージメント）

【本文】
---（ここに投稿文）---



（ここにハッシュタグ）
---

【文字数】XX字（上限280字 / 日本語ツイートは140字前後が目安）

【画像・動画の有無】
□ なし  □ 静止画  □ 動画  □ GIF
→ 内容・指示:

【チェックリスト】
□ 最初の1〜2行で続きを読みたいと思わせているか
□ 具体的な数字・事例が入っているか（必要な場合）
□ 誇大表現・リスクのある表現が含まれていないか
□ ハッシュタグは3〜5個以内か
□ CTAが自然に入っているか（必要な場合）
```

---

## 単発投稿の例

```
【投稿日時】2026/03/27 07:30

【投稿分類】
✅ 知識・Tips

【目的】フォロワー獲得・保存数増加

【本文】
---
プルアップが増えない人の9割がやっている間違い

・手幅が広すぎる
・肩甲骨が使えていない
・スタート姿勢が死んでいる

この3つを直すだけで、
来週には1〜2回は増える。

やり方は画像で解説↓
---

#カリステニクス #プルアップ #筋トレ初心者

【文字数】88字

【画像・動画の有無】
✅ 静止画
→ 3つのNG例とOK例を比較した図解画像（縦型・テキスト強調）
```
